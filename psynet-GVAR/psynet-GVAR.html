縦断デザインデータの種類

縦断デザインデータの種類としては，以下がある。

  • 単一事例の時系列データ：対象＝個人，測定回数＝多い(経験サンプリング)
  • パネルデータ：対象＝集団，測定回数＝数回
  • 集団の時系列データ：対象＝集団，測定回数＝多い(経験サンプリング)

個人内効果，個人間効果，固定効果

  • 個人内効果：「Aが高くなった時は，Bも高くなる」のような個人内の変動を扱う<単一事例の時系列データ>

  • 個人間効果：「平均的にAが高い人は，平均的にBも高い傾向がある」のように個人内の変動ではなく集団内での変動を扱っている（時間の情報を平均化）＜パネルデータ＞

  • 固定効果：「平均的な人の個人内効果」を扱う（集団を平均化）。メタ分析の固定効果と同じで，平均的な個人効果に変動が含まれたのが個人のデータとしている＜集団の時系列データ＞

個人内効果，個人間効果，固定効果

心理学研究では，あまり個人内効果，個人間効果，固定効果を区別してないが，分けて考える。個人内ではタイピングを早くするほどミスが多くなるが，個人間ではタイピングが早い人ほどミスは少ないこともある(Epskamp et al., 2018)。

デザインと効果は完全に対応しないこともある（変数によって変わる）。

特に，横断データの分析では，個人内効果と個人間効果が混ざってしまっている。心理ネットワーク分析領域では，個人内効果こそが心理学において関心のあるものではないかと考える。

経時的効果と同時性効果

時系列データでは，前の時点からの影響性を考慮したベクトル自己回帰(vector auto-regression)モデルが使われる。ネットワーク分析では，グラフィカルVAR(graphical VAR)があり，以下のネットワークが描ける

  • 経時的ネットワーク(temporal network)：時点をまたいで生じる関連から作られた有向ネットワーク

  • 同時性ネットワーク(contemporaneous network)：同一時点で生じる関連から作られた無向ネットワーク

N>1なら安定的な平均的な関連を集団で検討した個人間ネットワーク(between-person network)も描ける。

経時的効果と同時性効果(詳細)

  • 経時的ネットワーク（個人ごと）：ある個人の変数の平均値からの偏差が，次の時点における平均値からの偏差をどの程度うまく予測できる程度（ネットワークには，自己ループ（自己回帰）とエッジ（交差遅延回帰）が含まれる）

  • 同時性ネットワーク（個人ごと）：経時的効果を統制したうえでの同一時点での変数間の関連（横断データのネットワークとは異なる）

  • 個人間ネットワーク（集団）：集団データをもちいて，平均的な人の推定値（固定効果）を示す

N=1データ分析:トレンドの除去

ネットワーク分析の常道手段ではないが，時間による変化（トレンド）がある場合は，それを除去する（デトレンド）方法もある（時間で回帰分析してその残差を使う）。

for (v in seq_along(Vars1)){
  ff <- as.formula(paste0(Vars1[[v]]," ~ time"))
  fit <- lm(ff, data = data1)
  if (anova(fit)$P[1] < 0.05){
    message(paste("Detrending variable",v))
    data1[[Vars1[v]]][!is.na(data1[[Vars1[[v]]]])] <- residuals(fit)
  }
}

N>1データ分析

  • N>1のデータなら参加者間ネットワークも推定できる。

  • 参加者間ネットワークの推定は，マルチレベルになる（集団の平均的なネットワークに，個人のネットワークがネストする）。マルチレベル解析により，個人の参加者からの回答数が少なくても推定が安定するなどの利点がある。

  • 推定には，2ステップ・マルチレベルGVARを用いる。mlVARパッケージで推定できるが，各個人から20回以上の測定が必要になる（測定回数の少ないパネルデータについてはパネルGVARを適用し，psychonetricsパッケージを用いいる）。

N>1データ分析での注意事項

  • 推定が適切になされるために変数はできるだけ少数にする（10以下）

  • 欠測値には，カルマンフィルター代入法などを用いるか（imputeTSパッケージ），完全情報最尤推定法（psychonetricsパッケージ）を使える。

  • GVARでは定常性（測定全体でネットワークが大きく変化しないこと）を仮定（デトレンドなども検討）

  • GVARでは，測定間隔は等間隔が仮定されている（パッケージ上で指定）。
